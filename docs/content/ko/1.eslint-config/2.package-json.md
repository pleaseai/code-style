# Package JSON Lint

`@pleaseai/eslint-config`는 `package.json` 파일을 린트하기 위한 [`eslint-plugin-package-json`](https://github.com/JoshuaKGoldberg/eslint-plugin-package-json)의 설정도 함께 export합니다.

## 사용법

```ts [eslint.config.ts]
import { recommended, stylistic } from '@pleaseai/eslint-config/package-json'

export default [
  recommended,
  stylistic,
]
```

### 사용 가능한 설정

| Export | 설명 |
|--------|-------------|
| `recommended` | 배포 가능한 패키지를 위한 권장 규칙 |
| `stylistic` | 일관된 `package.json` 포매팅을 위한 스타일 규칙 |

### ESLint Config와 함께 사용

```ts [eslint.config.ts]
import pleaseai from '@pleaseai/eslint-config'
import { recommended } from '@pleaseai/eslint-config/package-json'

export default pleaseai(
  {},
  recommended,
)
```
