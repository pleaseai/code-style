# EditorConfig

`@pleaseai/editorconfig`은 PleaseAI 프로젝트 전반에 걸쳐 일관된 에디터 설정을 위한 공유 `.editorconfig` 파일을 제공합니다.

## EditorConfig란?

[EditorConfig](https://editorconfig.org/)는 서로 다른 에디터와 IDE에서 일관된 코딩 스타일을 유지할 수 있도록 도와줍니다. 대부분의 최신 에디터는 기본 또는 플러그인을 통해 이를 지원합니다.

## 사용법

이 패키지의 `.editorconfig` 파일을 프로젝트 루트로 복사하거나, 프로젝트 설정 스크립트에서 패키지를 참조하세요.

## 지원 에디터

- VS Code (기본 지원 또는 [EditorConfig 확장](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig)을 통해)
- JetBrains IDE (기본 지원)
- Vim/Neovim (플러그인을 통해)
- Sublime Text (플러그인을 통해)
