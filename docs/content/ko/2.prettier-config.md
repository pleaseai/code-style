# Prettier Config

`@pleaseai/prettier-config`은 PleaseAI 프로젝트 전반에 걸쳐 일관된 포매팅을 위한 공유 Prettier 설정을 제공합니다.

## 설치

:::code-group
```bash [bun]
bun add -D @pleaseai/prettier-config prettier
```

```bash [pnpm]
pnpm add -D @pleaseai/prettier-config prettier
```

```bash [npm]
npm install -D @pleaseai/prettier-config prettier
```
:::

## 사용법

`package.json`에서 참조합니다:

```json [package.json]
{
  "prettier": "@pleaseai/prettier-config"
}
```

또는 `.prettierrc.json`을 생성합니다:

```json [.prettierrc.json]
"@pleaseai/prettier-config"
```

### 확장

특정 옵션을 오버라이드하려면 `.prettierrc.mjs`를 생성하세요:

```js [.prettierrc.mjs]
import config from '@pleaseai/prettier-config'

export default {
  ...config,
  printWidth: 100,
}
```

## 설정값

| 옵션 | 값 |
|--------|-------|
| `singleQuote` | `true` |
| `semi` | `false` |
| `useTabs` | `false` |
| `tabWidth` | `2` |
| `endOfLine` | `auto` |
| `bracketSpacing` | `false` |
| `arrowParens` | `always` |
| `bracketSameLine` | `false` |
| `printWidth` | `120` |
| `trailingComma` | `all` |

## 호환성

- Prettier `^2.8.8` 또는 `^3.0.0`
