# Notice

The language guides in this directory are Passion Factory's own condensed
rules. Several are adapted from third-party style guides. The text of each
guide was condensed, reworded, and merged with Passion Factory rules
(ADR-0022), so it is not a copy of any source. The sources and their licenses
are listed below.

## Conductor code style guides (Apache-2.0)

[gemini-cli-extensions/conductor](https://github.com/gemini-cli-extensions/conductor),
`skills/conductor-setup/assets/code_styleguides/`, Apache License 2.0. The full
license text is in [`LICENSE-Apache-2.0.txt`](./LICENSE-Apache-2.0.txt). We
changed the text as described above.

- `general.md` (Principles section): conductor `general.md`.
- `dart.md`, `go.md`, `python.md`, `ruby.md`, `csharp.md`, `html-css.md`: the
  conductor summary of the same name, together with the upstream guide below.
